Stopwatch Web Application

SkillCraft Technology — Web Development Internship (Task 02)

📌 Project Overview

This project is an interactive Stopwatch Web Application developed using HTML, CSS, and JavaScript.

It allows users to accurately track elapsed time, pause and resume the stopwatch, reset the timer, and record multiple lap times through a simple and responsive interface.

✨ Features

- Start the stopwatch.
- Pause and resume functionality.
- Reset the timer.
- Record multiple lap times.
- Display hours, minutes, seconds, and centiseconds.
- Interactive control buttons.
- Responsive design for mobile and desktop.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the "index.html" file.
4. Run using Live Server or open it directly in your browser.
5. Click Start to begin using the stopwatch.

⚙️ How It Works

- Start: Begins or resumes the stopwatch.
- Pause: Temporarily stops the timer.
- Lap: Records the time taken for each lap.
- Reset: Resets the stopwatch and clears all recorded laps.
